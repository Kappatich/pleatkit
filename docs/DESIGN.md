# Morphkit: дизайн-система v3 «Swiss grid + timetable»

Дата: 2026-10-18 (третья версия, выбор Minte по галерее из 100 направлений: e01 Swiss grid poster и d17 Swiss railway timetable). Применяется к лендингу (`site/`), шторке (`@morphkit/ui`, прототип `docs/prototypes/drawer-swiss.html`), админке и документации.

## 0. История
v1 «чертёжный стол» (бежевая бумага, serif, оранжевый) отклонён: узнаётся как стиль Anthropic. v2 «cyanotype» (синька, жёлтый маркер) отклонён: та же компоновка в других цветах. v3 меняет структуру, а не краску: плакатная вёрстка и расписание вместо карточек.

## 1. Идея
Швейцарская международная школа: флаговая вёрстка, одна нейтральная гарнитура, жёсткая асимметричная сетка, чёрные линейки как структура, один красный. Расписание SBB для всего табличного: версии, запросы, цены, шаги.

Правила:
1. **Линейки вместо карточек.** Блок начинается с чёрной линии сверху, не с рамки с тенью. Карточек, скруглений и теней нет.
2. **Один красный.** Только текущая версия, главное действие и выделение редактируемой зоны. Всё остальное чёрное, серое, белое.
3. **Таблица там, где список.** История версий, запросы в админке, тарифы, шаги установки это строки расписания с табличными цифрами и временем.
4. **Числа как плакат.** Измеренные значения крупно, флагом влево, подпись моноширинным.
5. **Композер как в редакторах.** Одно поле внизу, Enter отправляет, инструменты внутри рамки, стоп вместо отправки во время работы; подробности в brainstorm 14.

## 2. Токены
```css
--paper: #ffffff; --paper-2: #f4f4f2; --ink: #111111; --ink-2: #4a4a4a; --ink-3: #8a8a8a;
--rule: #d9d9d9; --rule-2: #bdbdbd; --red: #e30613; --red-ink: #b8000f; --ok: #1a7f37;
/* dark: paper #161616, ink #f2f2f2, red #ff3b30 */
```
Шрифты: **Helvetica Neue / Helvetica / Arial** (система) с запасной **Public Sans** из Google Fonts; подписи и цифры **JetBrains Mono**. В шторке внутри чужого приложения веб-шрифты не грузим: системный стек.

Типографика: h1 `clamp(44px, 7.2vw, 104px)` с межстрочным 0.92 и трекингом −0.03em, текст 16/1.5, подписи 11.5px mono верхним регистром с трекингом 0.1em, табличные цифры везде, где есть числа.

Геометрия: радиусы 0, тени нет, границы 1px `--ink` для структуры и `--rule` для второстепенного, красная кромка 3px для редактируемой зоны.

## 3. Компоненты
| Компонент | Как выглядит | Где |
|---|---|---|
| Poster block | Чёрная линия сверху, mono-подпись, заголовок жирным, текст до 48 символов в строке | боль, «что это не», CTA |
| Timetable | Колонки: номер (mono), название, время (табличные цифры), действие; текущая строка подчёркнута красным 2px и подписана NOW | история версий, запросы в админке, тарифы, шаги |
| Dims row | Четыре числа в одной строке между двумя чёрными линиями, разделены серыми | измеренные значения |
| Zone map | Сетка блоков с чёрными линиями: core серый, readonly с горизонтальной штриховкой, editable с красной кромкой | «как работает», легенда в админке |
| Composer | Рамка 1px, поле растёт 1–6 строк, «⌖ Pick panel» и скрепка слева внизу, отправка квадратом справа (красная, когда есть текст; чёрный квадрат «стоп» во время работы) | шторка, hero |
| Progress | Одна живая строка с красным ▸ и таймером; по завершении ✓ и сводка, шаги за «N steps ›» | шторка |
| Icon button | 32×32, без фона, рамка при наведении, подсказка снизу; только ↶ ↷ × ↑ без подписи | шторка |
| Chip | Рамка 1px серая, при наведении чёрная; рецепты и выбранная панель | шторка, hero |
| Banner | Строка с красной верхней кромкой 3px | stale, safe-mode |

## 4. Движение
Подмена панели: красная кромка на 450 мс заливает блок и возвращается в полоску. Строки прогресса появляются по одной. Ничего другого; `prefers-reduced-motion` отключает всё.

## 5. Лендинг
Hero: сетка 7+5, слева подпись, заголовок флагом с красной ключевой фразой, лид и две кнопки; справа живая шторка (панель, расписание версий, прогресс, композер, рецепты). Ниже строка измеренных чисел, ролик, боль двумя колонками плакатных блоков, «как работает» с картой зон, «что это не», установка в пять строк, цены как расписание, FAQ с номерами, CTA.

## 6. Чего не делаем
Карточки со скруглением и тенью, градиенты, стекло, свечение, иллюстрации, иконки с заливкой, искорки, Inter/Space Grotesk/serif, бежевая бумага, оранжевый и жёлтый акценты, текстовые кнопки там, где хватает одной иконки.
