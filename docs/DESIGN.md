# Morphkit: дизайн-система

Дата: 2026-10-18. Автор: архитектор. Применяется к лендингу (`site/`), чат-шторке и дашборду (`@morphkit/ui`, `apps/demo-crm/admin`) и документации.

## 1. Идея

Morphkit меняет интерфейс на лету, под человека. Визуальный язык берём не из «ИИ-сайтов» (фиолетовые градиенты, стекло, скруглённые карточки, искорки), а из **чертёжного стола**: бумага, тушь, одна сигнальная краска, размерные линии, штриховка зон. Интерфейс выглядит как чертёж, который можно править карандашом, и это буквально то, что делает продукт.

Три правила:
1. **Чертёж, а не витрина.** Сетка видна, размеры подписаны, зоны заштрихованы. Декор несёт смысл: размерная линия показывает реальное число (≈100 ms), штриховка показывает, что агент может трогать.
2. **Одна краска.** Тушь и бумага плюс сигнальный оранжевый для «динамического» и «действия». Синий пунктир только для readonly. Больше цветов нет.
3. **Живое, а не нарисованное.** Главный экран лендинга это рабочая панель, которую посетитель меняет сам (без модели, по сценариям). Ролик второй, не первый.

## 2. Токены

```css
:root {
  --paper: #f3efe6;        /* бумага */
  --paper-2: #e9e4d8;      /* вторая бумага, подложки */
  --ink: #15120f;          /* тушь */
  --ink-2: #4a443c;        /* серая тушь, вторичный текст */
  --ink-3: #8c8378;        /* подписи, размерные линии */
  --rule: #c9c1b2;         /* линии сетки, границы */
  --signal: #f0532d;       /* сигнальный оранжевый: dynamic, действие */
  --signal-ink: #b93a1b;   /* оранжевый на бумаге для текста */
  --signal-wash: #fde4db;  /* оранжевая отмывка */
  --blueprint: #2b5fd9;    /* readonly, пунктир */
  --blueprint-wash: #dde6fb;
  --ok: #2f7a3f;
  --shadow: 4px 4px 0 var(--ink); /* жёсткая тень, без размытия */
}
:root[data-theme="dark"], @media (prefers-color-scheme: dark) {
  --paper: #121110; --paper-2: #1b1917; --ink: #ece7dc; --ink-2: #b9b1a3; --ink-3: #7e766b;
  --rule: #332f2a; --signal: #ff6a45; --signal-ink: #ff8a6a; --signal-wash: #3a1d14;
  --blueprint: #7ea2ff; --blueprint-wash: #1b2642; --ok: #6cc97d; --shadow: 4px 4px 0 var(--ink);
}
```

Шрифты (Google Fonts): заголовки **Instrument Serif** (курсив для акцента), текст **IBM Plex Sans**, подписи и код **IBM Plex Mono**. Никакого Inter.

Размеры: базовый 17px/1.55; заголовки `clamp(40px, 7vw, 88px)` с межстрочным 0.95; подписи 12–13px mono в верхнем регистре с трекингом 0.08em.

Радиусы: 2px везде. Границы 1px `--rule`, акцентные 1.5px `--ink`. Тень только жёсткая (`--shadow`), только у интерактивных и «приподнятых» элементов.

## 3. Компоненты

| Компонент | Как выглядит | Где |
|---|---|---|
| **Spec card** | Бумажная карточка с угловыми метками (crop marks) в четырёх углах, mono-подпись сверху слева («03 / ZONE: DYNAMIC»), заголовок serif | карточки боли, тарифы, «что это не» |
| **Zone hatch** | Dynamic: диагональная оранжевая штриховка 45°, шаг 6px, по краю сплошная линия. Readonly: синий пунктир. Core: ровная серая заливка | схема зон, легенда, бейджи в дашборде |
| **Dimension line** | Тонкая линия с засечками на концах и mono-подписью по центру («≈ 100 ms», «1 user») | метрики на лендинге, статистика в админке |
| **Version ruler** | Горизонтальная линейка с делениями; каждая версия это деление с меткой; текущая отмечена оранжевым треугольником; undo двигает треугольник влево | история в шторке, лента в админке |
| **Diff ribbon** | Две полосы «было / стало» рядом, изменённые строки подчёркнуты оранжевым, удалённые перечёркнуты | админка, «что изменилось» для пользователя (словами) |
| **Button** | Прямоугольник 2px, тушь на бумаге; primary: оранжевая заливка, тушь текст, жёсткая тень; при нажатии тень исчезает и кнопка сдвигается на 2px | везде |
| **Prompt bar** | Поле с mono-префиксом `>` и мигающим курсором, под ним «рецепты» как чипы с пунктирной рамкой | шторка, hero |
| **Progress lines** | Моноширинные строки с маркером `·` и временной меткой слева, последняя с оранжевым `▸` | шторка |
| **Banner** | Полоса с оранжевой левой кромкой 4px, без скругления | stale, safe-mode, ошибка |

Иконки: только линейные, 1.5px, из одного набора (Lucide), без заливки. Никаких эмодзи и искорок.

## 4. Движение

Только то, что объясняет: подмена панели это короткая вспышка штриховки по краю (200 ms) и сдвиг треугольника на линейке; строки прогресса появляются по одной; никаких parallax, blur и плавающих градиентов. `prefers-reduced-motion` отключает всё.

## 5. Лендинг

Hero: слева заголовок serif и текст, справа **живая панель**: карточка клиента на бумаге с штриховкой по краю (это зона), под ней prompt bar с четырьмя рецептами. Клик по рецепту меняет карточку (скриптом, без модели), появляется линейка версий, кнопка «Undo» возвращает. Подпись mono: «Scripted on this page. In the app the agent writes the code.» Это честно и показывает суть за 5 секунд.

Дальше по порядку: размерные линии с реальными числами, боль (spec cards, две колонки), как работает (четыре шага как чертёж зон), «что это не», установка (код на тёмной бумаге), цены (три spec card, Cloud с оранжевой кромкой), FAQ (mono-номера), CTA.

## 6. Чего не делаем

Градиенты, стекло, blur, свечение, фиолетовый, иллюстрации роботов, «AI-искорки», карусели логотипов, фейковые аватары, анимированные счётчики.
