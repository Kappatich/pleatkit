# Morphkit: дизайн-система «Cyanotype»

Дата: 2026-10-18 (вторая версия). Применяется к лендингу (`site/`), чат-шторке и дашборду (`@morphkit/ui`, `apps/demo-crm/admin`) и документации.

## 0. Почему вторая версия

Первая версия («чертёжный стол»: бежевая бумага, тушь, оранжевый, serif-курсив) узнавалась как фирменный стиль Claude. Правило теперь прямое: **ничего из того, что ассоциируется с ИИ-брендами.** Запрещены: тёплая бежевая бумага с serif и оранжевым (Anthropic), чёрно-фиолетовые градиенты, стекло и свечение (OpenAI и клоны), Inter и Space Grotesk, скруглённые карточки с мягкими тенями, искорки, иллюстрации роботов, анимированные градиенты.

## 1. Идея

**Цианотипия.** Синька, на которой инженеры размножали чертежи: прусская синь, белая линия, жёсткая сетка, и один маркер-выделитель поверх, которым отмечают правку. Это про продукт: в живом приложении (синька) появляется правка (жёлтый маркер), и видно, где именно.

Три правила:
1. **Сетка видна и честна.** Фон это разлинованная синька с шагом 96px; размеры, версии и зоны подписаны моноширинным шрифтом в верхнем регистре.
2. **Два цвета и маркер.** Синь и белая печать. Жёлтый маркер только для того, что изменил агент, и для главного действия. Голубой пунктир только для readonly. Больше цветов нет.
3. **Живое, а не нарисованное.** Главный экран лендинга это рабочая панель, которую посетитель меняет сам по сценариям; подмена отмечается жёлтой штриховкой по краю зоны.

## 2. Токены

```css
:root { /* тёмная синька, основная */
  --paper: #0d2b5c; --paper-2: #0a2349; --paper-3: #113570;
  --ink: #eaf2ff; --ink-2: #b7c9ea; --ink-3: #7f98c6;
  --rule: #2a4f8f; --rule-2: #3b63a6;
  --signal: #ffd23f; --signal-wash: rgba(255,210,63,.14);   /* маркер */
  --blueprint: #8fd6ff; --blueprint-wash: rgba(143,214,255,.12); /* readonly */
  --ok: #7ef0b0;
}
/* светлый вариант (prefers-color-scheme: light): белый лист, синяя печать, тот же жёлтый */
--paper: #f4f7fc; --ink: #0d2b5c; --rule: #c6d3ea; --signal: #ffcf1f; --signal-ink: #8a6a00;
```

Шрифты (Google Fonts): **Archivo** с переменной шириной (заголовки и логотип `font-stretch: 112%`, вес 700, трекинг −0.03em), текст Archivo 400, подписи и код **Azeret Mono**. Никакого Inter, Space Grotesk, serif.

Размеры: текст 17px/1.55; h1 `clamp(40px, 6vw, 78px)` с межстрочным 0.98; подписи 11.5px mono, верхний регистр, трекинг 0.12em.

Геометрия: радиусы 0 везде. Границы 1px `--rule-2`, акцентные 1.5px `--ink`. Тень только как кольцо `0 0 0 1px --rule-2` плюс мягкий сброс вниз для «приподнятых» листов. Углы карточек отмечены метками 9px.

## 3. Компоненты

| Компонент | Как выглядит | Где |
|---|---|---|
| **Sheet** | Лист синьки с внешней пунктирной рамкой на 9px, mono-подписи в шапке («ZONE: DYNAMIC · customer-card.tsx») | живая панель, карта зон |
| **Frame (card)** | Прямоугольник с угловыми метками, mono-подпись сверху («01 / BACKLOG»), заголовок Archivo expanded | боль, тарифы, «что это не», CTA |
| **Zone hatch** | Dynamic: диагональная жёлтая штриховка −45°, шаг 6px, по левому краю зоны. Readonly: голубой пунктир. Core: ровная синь | карта зон, бейджи в админке |
| **Marker** | Жёлтая полоса под ключевой фразой заголовка (как выделитель на чертеже), не подчёркивание | h1/h2 |
| **Dimension line** | Линия с засечками на концах и mono-подписью, число Archivo expanded | метрики |
| **Version ruler** | Линейка с делениями под листом; текущая версия отмечена жёлтым треугольником | история в шторке, лента в админке |
| **Button** | Прямоугольник 1.5px без радиуса, mono-текст; уголок-метка справа снизу; primary: жёлтая заливка с синим текстом; hover инвертирует | везде |
| **Prompt bar** | Поле с mono-префиксом `>` и жёлтым мигающим курсором; под ним рецепты как чипы с пунктирной рамкой | шторка, hero |
| **Progress lines** | Моноширинные строки с `·`, текущая с жёлтым `▸`, готовая зелёная | шторка |
| **Banner** | Полоса с жёлтой верхней кромкой 4px | stale, safe-mode, ошибка |

Иконки: линейные 1.5px (Lucide), без заливки. Никаких эмодзи.

## 4. Движение

Только объясняющее: подмена панели это вспышка штриховки по краю (500 ms) и сдвиг треугольника на линейке; строки прогресса появляются по одной; никаких parallax, blur, плавающих градиентов. `prefers-reduced-motion` отключает всё.

## 5. Лендинг

Hero: слева заголовок Archivo expanded с жёлтым маркером на ключевой фразе, справа живой лист с панелью, линейкой версий и prompt bar с шестью рецептами (включая «discount on the server», который уходит администратору). Дальше: размерные линии с реальными числами, ролик, боль двумя колонками, «как работает» с картой зон, «что это не» (дополнить Gigacatalyst, Puck, v0), установка на тёмной синьке, цены (Cloud с жёлтой кромкой), FAQ с mono-номерами, CTA.

## 6. Чего не делаем

Градиенты, стекло, blur, свечение, бежевая бумага, serif, фиолетовый, оранжевый как акцент, иллюстрации роботов, искорки, карусели логотипов, фейковые аватары, анимированные счётчики, Inter/Space Grotesk.
